## 1. 核心循环

```
镇压异想体 / 提取探索 / 用钱兑换
            ↓ 获得
         脑啡肽
            ↓ 消耗
  E.G.O 开发（定向 / 随机抽卡）
            ↓ 变强
      镇压更高等级的异想体

## 2. 脑啡肽（原文写作「脑腓肽肤」❓）

**获取途径**

1. **镇压异想体** — 按异想体等级区间产出

## 6. 实现蓝图（第一版要写的模块）

```
src/main/java/<包名>/
├── VibePlugin/主类          # 生命周期、注册命令与监听器、加载配置
├── config/                  # 配置读取与校验（tiers.yml、abnormalities.yml、ego.yml、gacha.yml）

**命令草案**

## 11. 脑啡肽 / 异想体 / E.G.O（第三页）

**脑啡肽**：核心插件的基础货币。接入 Vault 后 **100 金钱 → 1 脑啡肽**，单向且不可撤销；此外可以通过镇压异想体获取。价格写入 `config.yml` 使其可配置。

**异想体**：从人类潜意识中出现、可「提取」的怪物。分 **Z / T / HE / WAW / A** 五阶等级；等级越高，镇压获得的脑啡肽越多、提取的根率（成功率）越高、对应的 E.G.O 越强，镇压难度也越高。另有一类**工具型异想体**，提取后可当作工具（道具）使用，但**有代价**（细则待定）。异想体应能在配置文件中设置：禁用/生成开关、生成机率、等级、黑名单，以及**只在指定世界生成 / 不生成**（计划与多世界插件联动）。

**E.G.O**：本插件最显著的特色装备。不同 E.G.O 的获取方式有差异，大多数需要通过「开发」获取；由**护甲、武器、饰品**三部分组成，均为**无限耐久**。

- 护甲 = 头饰 + 胸甲 + 护腿 + 靴子四件套
- **不可与原版装备或其他 E.G.O 混搭**；一旦混搭，所有 E.G.O. 的抗性特性全部失效
- 护甲无法破坏，也**不提供原版护甲值/韧性**，防御完全由**统一抗性值**承担
- 每套 E.G.O. 只有一个统一抗性 `x`，对 Minecraft 传入的**所有伤害类型**生效，不按原版伤害来源拆分
- `x` 不在代码中限制范围，直接使用 `ego.yml` 配置值（例如失乐园 `x=0.1`）
- `y` 只统计**同一套有效 E.G.O. 防具**件数，范围为 0~4；武器和饰品不计入，也没有部位权重

```
r = 1 - (1 - x) * y / 4
最终伤害 = 当前伤害 * r
```

- 计算保持 `double`，不主动取整，最终交给 Minecraft 处理
- 攻击侧只定义 `RED`（红伤）与 `BLUE`（蓝伤）两条通道；**蓝伤只能由 E.G.O. 来源造成**
- 蓝伤对应 Project Moon 的 PALE 机制：配置值 `5` 表示扣除目标最大生命值的 `5%`，再进入 E.G.O. 抗性结算
- `正义裁决者` 使用 2 秒时间轴多段攻击；普通攻击 5 段，40% 概率触发 3 次重击 + 7 次轻击
- `失乐园` 铁甲提供按件数成长的生存效果；四件套在乘 `x=0.1` 后最终伤害严格 `<5` 时免疫，并以最高 20 点的神圣黄盾阻挡一次超量伤害
- `失乐园` 铁锄支持 16 格攻击、命中回血/减速，每 20 秒发动前方 `8 × 3 × 8` 特殊攻击；主动技能召唤 12 位限时使徒
- E.G.O. 防具不能附魔，也不能通过铁砧或 `/enchant` 绕过限制
