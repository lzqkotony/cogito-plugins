## 1. 核心循环

```
镇压异想体 / 提取探索 / 用钱兑换
            ↓ 获得
         脑啡肽
            ↓ 消耗
  E.G.O 开发（定向 / 随机抽卡）
            ↓ 变强
      镇压更高等级的异想体
```

## 2. 脑啡肽（原文写作「脑腓肽肤」❓）

**获取途径**

1. **镇压异想体** — 按异想体等级区间产出
2. **提取探索** ❓（机制待你补一句描述）
3. **用钱兑换** — 每 100 元兑换 1 脑啡肽，**单向**（不可逆）

**用途**

- E.G.O 开发
- 提取

## 3. 等级与数值区间（已确认）

**含义：镇压一个该等级的异想体，产出的脑啡肽数量（在此区间内随机取值）。** 由你在 2026-09-15 确认。

| 等级 | 区间（手写） |
| --- | --- |
| ALEPH（手写 Alpha） | 100 ~ 60 |
| WAW（手写像 man/wav） | 60 ~ 30 |
| HE | 30 ~ 20 |

> 2. 区间是「随等级递减」的（ALEPH 最多、ZAYIN 最少），和原作强度手感一致。

## 4. E.G.O 开发

**定向开发**

- 解锁条件：某个异想体被**累计镇压 5 次**，解锁该异想体的 E.G.O 开发
- 消耗：指定量的脑啡肽
- 三档风险：

| 档位 | 失败率 | 费用 |
| --- | --- | --- |
| 普通定向开发 | 50% | 基准价 |
| 高级定向开发 | 25% | 基准价 +20% |
| 决断定向开发 | 0% | 基准价 +50% |

**随机开发（抽卡）**

- 形式：抽卡，池子设计 ❓（卡池构成、权重、保底规则等待定）

## 6. 实现蓝图（第一版要写的模块）

```
src/main/java/<包名>/
├── VibePlugin/主类          # 生命周期、注册命令与监听器、加载配置
├── config/                  # 配置读取与校验（tiers.yml、abnormalities.yml、ego.yml、gacha.yml）
├── data/                    # SQLite 存储：玩家余额、镇压次数、解锁记录
├── enkephalin/              # 脑啡肽发放/扣除/兑换逻辑
├── abnormality/             # 异想体：生成、死亡监听、等级归属、镇压计数
├── ego/
│   ├── item/                # E.G.O 物品工厂（原版物品+名字+Lore+属性+模型数据）
│   ├── development/         # 定向开发：解锁判定、三档成功率、费用计算
│   └── gacha/               # 随机开发：卡池与权重
└── command/                 # /enkephalin、/ego、/exchange、/abnormality（管理员）
```

**命令草案**

| 命令 | 作用 | 权限 |
| --- | --- | --- |
| `/enkephalin` | 查看自己的脑啡肽余额 | 所有人 |
| `/exchange <数量>` | 用钱兑换脑啡肽（100:1，单向） | 所有人 |
| `/ego list` | 查看已解锁 / 可开发的 E.G.O | 所有人 |
| `/ego develop <异想体> <普通\|高级\|决断>` | 定向开发 | 所有人 |
| `/ego gacha <池子> [次数]` | 随机开发（抽卡） | 所有人 |
| `/abnormality spawn <id> [数量]` | 手动生成异想体（调试用） | 管理员 |

**配置草案**：`tiers.yml`（等级与数值区间）、`abnormalities.yml`（异想体定义：生物类型/等级/血量/掉落/解锁所需镇压次数）、`ego.yml`（E.G.O 装备：所属异想体、基础物品、属性、模型数据、开发基准价）、`gacha.yml`（卡池权重）。
