# Cogito 0.2.0 Beta

第二个测试版：在 0.1 的脑啡肽经济之上，加了**物品注册表**与**箱子 GUI**。

## 这个版本有什么

### 物品注册表（items.yml）

| id | 名称 | 原型 | 备注 |
| --- | --- | --- | --- |
| `pe` | 脑啡肽 | 绿宝石 | 基础货币，别名 `PE` / `enkephalin` |
| `pe-module` | 脑啡肽模块 | 绿宝石块 | 提取异想体所必备，别名 `PE-BOX` |
| `cogito` | Cogito | 跳跃药水 | 原版药水不能堆叠，这里改成 64 |
| `ego-blueprint` | E.G.O 研发图纸 | 纸 | 后续 E.G.O 开发消耗 |
| `golden-bough` | 金枝 | 树枝 | 脑叶公司奇点的核心浓缩 |

所有物品：

- 统一打 NBT 标签 `cogito:item=<id>`，玩家改名、附魔、堆叠都不会失效，也无法伪造
- **不可放置、不可参与合成**（可在 items.yml 里按物品开回来）
- 老版本的 `cogito:enkephalin` 标签通过 `legacy-tags` 继续识别，**老物品不会变废纸**

### 箱子 GUI

`/cogito gui`（别名 `/cog`、`/box`，或 `/enkephalin box`）打开箱子样式菜单：持有量、余额、×1 / ×8 / ×64 兑换按钮、命令帮助、管理员配置与重载、关闭。菜单物品锁死，点不走也拖不走。

### 命令

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/cogito gui` | 打开箱子界面 | 所有人 |
| `/cogito items` | 列出所有已注册物品 | `cogito.admin` |
| `/cogito give <物品id> <玩家> <数量>` | 发放注册物品 | `cogito.admin` |
| `/cogito debug <物品id>` | 造一个物品并打印材质/NBT/识别自检 | `cogito.admin` |
| `/exchange [数量]` | 用钱兑换脑啡肽（100:1，单向） | 所有人 |
| `/enkephalin` | 查看持有量 | 所有人 |
| `/enkephalin give\|take <玩家> <数量>` | 发放 / 扣除脑啡肽 | `cogito.admin` |
| `/cogito reload` | 重载 config.yml 与 items.yml | `cogito.admin` |

## 环境要求

| 组件 | 版本 |
| --- | --- |
| 服务端 | Paper 1.21.11 |
| Java | 21 |
| Vault | 1.7+（用 `/exchange` 必需） |
| 经济插件 | EssentialsX / CMI 等 |

## 安装

1. 下载 `Cogito-0.2.0-BETA.jar`，放进服务端 `plugins/`
2. 确认服务端已装 **Vault + 经济插件**
3. 重启服务端，日志出现下面三行即成功：

```
[Cogito] 已注册 5 个物品：pe, pe-module, cogito, ego-blueprint, golden-bough
[Cogito] 已启用：脑啡肽物品 = EMERALD（标签 cogito:item）
[Cogito] Vault 经济已连接：EssentialsX Economy
```

4. 进服自测：`/cogito items` → `/cogito debug pe` → `/eco give <你> 10000` → `/exchange 10` → `/cogito gui`

## 文件校验

本 Release 附带 `Cogito-0.2.0-BETA.jar.sha256`，在服务器上用 `sha256sum -c` 或手动对照即可。
