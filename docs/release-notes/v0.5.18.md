# Cogito 0.5.18

## 恢复失乐园原始伤害免疫

- 恢复失乐园四件套的原始伤害免疫。
- 判定发生在全部防御计算之前：
  - 原始单次伤害 `<5`：直接免疫
  - 原始单次伤害 `>=5`：正常进入抗性、`x=0.1` 和黄盾结算
- 例如：
  - `4` 点原始伤害：免疫
  - `5` 点原始伤害：不免疫，进入后续结算
- 该判定只对失乐园 `y=4` 生效，其他套装不受影响。
- 黄盾、鞘翅混搭和拟态系统保持不变。
