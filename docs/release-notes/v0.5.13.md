# Cogito 0.5.13

## 失乐园免伤提前到结算前

- 四件套免伤判定从“原版抗性提升和 `x=0.1` 结算后”改为“所有防御计算前”。
- 现在只有单次原始伤害 `≤5` 才会直接免疫。
- 原始伤害超过 5 后，正常进入以下流程：
  1. 原版抗性提升等保护结算
  2. 失乐园统一抗性 `x=0.1`
  3. 神圣黄盾结算
  4. 最终才扣除生命值
- 这避免了原先把最终伤害门槛反向放大成“原始伤害 <83.33 全部免疫”的问题。
- 示例：锋利 X 下界合金僵尸单次约 `13.5` 原始伤害，不再直接免疫，而是继续受到抗性和 `x` 的削减。

## 保持不变

- 四件套仍提供 `+40` 最大生命、生命恢复 II、抗性提升 II、抗火 I、水下呼吸 I。
- 神圣黄盾仍按每 10 秒 1 点、上限 20 点工作。
- 失乐园武器、使徒、`±8` 攻击范围和右键技能不变。
