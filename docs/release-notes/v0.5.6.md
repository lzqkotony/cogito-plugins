# Cogito 0.5.6

## 正义裁决者：灵魂攻击机制

- 等级：ALEPH
- 研发武器基准 x：450
- 属性：灵魂
- 普通攻击：每轮 5 次固定灵魂伤害，每段 `4~8`
- 40% 概率特殊攻击：3 次重击 `14~20` + 7 次轻击 `4~8`
- 攻击距离：4 格
- 攻击速度：40 tick / 2 秒硬冷却
- 不设置额外装备条件

武器描述仅保留数值字段和：

> 它的天平能够绝对公正地衡量任何罪恶。
