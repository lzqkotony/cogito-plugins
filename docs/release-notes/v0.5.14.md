# Cogito 0.5.14

## 鞘翅允许混搭

- 胸甲槽中的普通鞘翅不再导致 E.G.O. 套装整体判定为混搭失效。
- 鞘翅被视为功能性装备，不提供 E.G.O. 套装件数。
- 玩家穿戴三个 E.G.O. 防具部件 + 鞘翅时：
  - 套装识别保持有效
  - 按 `y=3` 计算统一抗性
  - 不获得第四件防具对应的套装能力
- 其他部位混入原版防具或其他 E.G.O. 防具时，原有混搭失效规则不变。
- 自定义 E.G.O. 胸甲不会被误判为鞘翅；只有实际 `minecraft:elytra` 且不属于 E.G.O. 套装时按功能性装备处理。

## 神圣黄盾 ActionBar

- 黄盾数值变化时，在准星上方显示精确盾量，例如：
  `神圣黄盾 13.5/20`
- 黄盾满值且没有变化时每 5 秒刷新一次，方便持续观察。
- 黄盾被打破时显示：
  `神圣黄盾 已破碎`
