# Cogito 0.5.1

这一版完成 0.5.x 的第一轮小版本更新：研发流程改为一次性蓝图 + 四档成功率，并加入新的 E.G.O.「正义裁决者」。

## 一次性蓝图与四档研发

- 蓝图从“永久解锁物”改为**一次性装载物**：装载后消耗 1 张，并把该套 E.G.O. 的研发能力绑定给当前玩家
- 护甲与武器**分开研发**，可以分别设定基准脑啡肽消耗 `x`
- 四档定向研发：

| 档位 | 成功率 | 消耗 |
| --- | --- | --- |
| 普通研发 | 25% | 75% x |
| 进阶研发 | 50% | 100% x |
| 高级研发 | 75% | 150% x |
| 完全研发 | 100% | 200% x |

- 失败同样消耗脑啡肽，但不会返还
- 开发台新增主菜单、定向研发列表、蓝图装载页面；支持护甲/武器分类与分页

## 正义裁决者

- 四件防具统一抗性 `x=0.25`
- 按当前防具件数 `y` 叠加套装能力：
  - 每件 `+5` 最大生命上限
  - `y=3` 起 `+0.5` 攻击速度
  - `y=4` 再 `+0.5` 攻击速度、`+5` 攻击力，并解锁被动技能「审判」
- 「审判」：60 秒冷却，无法主动触发；被近战攻击时对攻击者造成 15 点蓝伤
- 武器「裁决之剑」：铁剑外观、攻速 `0.4`；满蓄力攻击前方 6 格、左右各 1 格，造成 5~6 点蓝伤并带蓝色粒子效果
- 设计稿基准研发消耗：护甲 `400`、武器 `450`

## 配置与底层能力

- `ego.yml` 支持 `develop.armor.cost` / `develop.weapon.cost` 分别配置
- 支持 `armor-trim` 海岸盔甲纹饰，以及配置化物品属性
- 新增按防具件数 `y` 动态生效的套装属性服务
- 负数抗性现在按易伤倍率计算，避免负伤害导致反向治疗
