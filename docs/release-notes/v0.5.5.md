# Cogito 0.5.5

## 金枝双端资源包

- 金枝由 `STICK` 改为 `DEAD_BUSH`，通过 `item_model: cogito:golden_bough` 使用自定义金色枯木模型。
- 新增 Java 资源包 `Cogito-Resources-JE.zip`。
- 新增 Bedrock/Geyser 资源包 `Cogito-Resources-BE.mcpack`。
- 新增 Geyser v2 mapping：`minecraft:dead_bush` + `cogito:golden_bough`。

## 下载

- [Java 资源包](https://github.com/lzqkotony/download/releases/download/v1.0.0/Cogito-Resources-JE.zip)
- [Bedrock 资源包](https://github.com/lzqkotony/download/releases/download/v1.0.0/Cogito-Resources-BE.mcpack)
- 国内代理使用 `https://v4.gh-proxy.com/` 前缀。

## 兼容

- Java：Paper 1.21.11，资源包格式 75。
- Bedrock：Geyser 自定义物品映射 v2，`enable-custom-content: true`。
- 旧的金枝物品会在玩家登录或 `/cogito reload` 时自动刷新，不会因材质变更失效。

## 验证

- `mvn clean test package`：BUILD SUCCESS，9/9 单元测试通过。
- 产物：`Cogito-0.5.5.jar`。
