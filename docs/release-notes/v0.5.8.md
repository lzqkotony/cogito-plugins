# Cogito 0.5.8

## 负抗性反转治疗

- E.G.O. 统一抗性仍使用公式 `r = 1 - (1 - x) * y / 4`。
- 负抗性现在保留负倍率，不再转换成正易伤倍率。
- 当 `x < 0` 且最终倍率为负数时：
  - 取消原版伤害
  - 将伤害绝对值转为治疗
  - 治疗不超过最大生命值
- 服主四件套 `x=-10` 时：
  - `r=-10`
  - 受到伤害时免疫并回血
- 部分穿戴同样生效，例如 `y=2` 时 `r=-4.5`。
