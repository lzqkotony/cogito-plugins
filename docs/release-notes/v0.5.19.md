# Cogito 0.5.19

## 失乐园免伤阈值提高到 10

- 按原著护甲资料调整四件套免伤：
  - 原始单次伤害 `≤10`：直接免疫
  - 原始伤害 `>10`：进入原版抗性、失乐园 `x=0.1` 和神圣黄盾结算
- 判定仍在全部防御计算之前。
- 示例：
  - `10.0` 原始伤害：免疫
  - `10.001` 原始伤害：不免疫
- 该阈值只对失乐园 `y=4` 生效。
