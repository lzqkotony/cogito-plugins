# Cogito 0.3.0 Beta

这一版加的是**玩家数据核心层（core data）**——为后面的异想体镇压产出和 E.G.O 解锁打底。

## 新增

### 玩家数据存储（SQLite）

- 数据库文件：`plugins/Cogito/cogito.db`（WAL 模式）
- 驱动用**服务端自带**的 `org.xerial:sqlite-jdbc`，插件不打包驱动、不引入额外依赖
- 三张表：
  - `players`：等级、首次上线、最近上线
  - `abnormality_suppression`：每个玩家对每种异想体的镇压次数
  - `ego_unlocked`：每个玩家已解锁的 E.G.O
- 读写策略：上线读档进内存缓存 → 改动只标脏 → 每 30 秒异步落库 → 玩家下线、插件关闭时立即写回

### 新命令

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/cogito set Lv <玩家> <数字>` | 设置玩家等级 | `cogito.admin` |
| `/cogito reset player_information <玩家>` | 重置该玩家数据（等级、镇压记录、E.G.O 解锁） | `cogito.admin` |
| `/cogito data <玩家>` | 查看玩家数据（在线、离线都能查） | `cogito.admin` |
| `/cogito debug db` | 数据库读写自检：写入 → 读回 → 删除 | `cogito.admin` |

`/cogito set` 目前只支持 `Lv`；`/cogito reset setting` 暂未实现（会给出提示）。

## 验证情况

在 Docker（Arch Linux WSL，Paper 1.21.11 + Vault 1.7.3 + EssentialsX 2.22.0）里实际启动过，插件加载与启用正常：

```

[Cogito] Enabling Cogito v0.3.0-BETA
[Cogito] 已注册 5 个物品：pe, pe-module, cogito, ego-blueprint, golden-bough
```

没有任何 Cogito 相关的异常。**建议装到正式服后先执行一次 `/cogito debug db`**，确认数据库能在你的环境下读写。

## 环境要求

Paper 1.21.11 / Java 21 / Vault + 经济插件（用 `/exchange` 时需要）。

## 安装

1. 把 `Cogito-0.3.0-BETA.jar` 放进服务端 `plugins/`
2. 重启服务端（或 `/reload confirm`）
3. 首次启动会生成 `plugins/Cogito/` 下的 `config.yml`、`items.yml`、`cogito.db`

## 文件校验

Release 附带 `Cogito-0.3.0-BETA.jar.sha256`，在服务器上 `sha256sum -c` 或手动对照。
