# Cogito 0.5.2

这一版集中修复「正义裁决者」在正式服实机测试中暴露的战斗问题。

## 修复

- 正义裁决者的四件防具与武器统一显示名称为 **正义裁决者**，不再附加头盔、胸甲、护腿、战靴或裁决之剑等后缀。
- 蓝伤改为 Project Moon PALE 规则：配置中的 `5~6` 表示每段扣除目标 **最大生命值的 5%~6%**，再经过 E.G.O. 抗性结算。
- 正义裁决者改为 **满蓄力挥剑即触发**，不再要求必须命中生物。
- 触发后对前方范围内的每个目标随机结算 **8~10 段**蓝伤，每段伤害随机为 `5%~6%` 最大生命值。
- 多段伤害会逐段结算，并清除受击无敌帧，避免后续段数被原版无敌时间吞掉。
- 修正正义裁决者套装在 `y=4` 时重复叠加攻速的问题：现在 `y>=3` 只额外提供一次 `+0.5` 攻击速度。
- 武器 NBT 仍直接带有攻击速度属性修正，铁剑模型基础攻速保持配置的 `0.4`；穿满套装后再叠加一次套装攻速。
- 玩家登录或执行 `/cogito reload` 时，背包内已有的 Cogito 自定义物品会按最新定义刷新；旧版正义裁决者会自动获得新名称、Lore 和 NBT，不需要重新发放。

## 验证

- 42 个生产源文件编译通过，9/9 单元测试通过。
- 新增蓝伤百分比回归测试。
