# Cogito 0.5.16

## 删除失乐园单次伤害免疫

- 完全删除 `damage-immunity-threshold` 配置和对应的 `blocksDamage()` 判定。
- 失乐园不再有“原始伤害 ≤5 免疫”或任何其他单次伤害硬免疫。
- 所有原始伤害统一进入：
  1. 原版抗性提升等保护
  2. 失乐园统一抗性 `x=0.1`
  3. 神圣黄盾
  4. 最终生命值结算
- 物品 Lore 已删除旧的免伤说明。
- 黄盾仍保持：
  - 每 10 秒增加 1 点
  - 上限 20 点
  - 首次获得套装时立即给 1 点
  - 伤害不超过盾量时扣盾
  - 伤害超过盾量时破盾且本次不穿透
  - ActionBar 显示精确盾量
