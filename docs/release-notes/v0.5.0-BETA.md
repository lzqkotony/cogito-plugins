# Cogito 0.5.0 Beta

这一版按 2026-09-17 设计稿实现 **E.G.O. 开发台**与**专属图纸解锁**。

## 开发台（自定义方块）

- **合成表**：四角 `下界合金块` ×4 / 四边 `脑啡肽模块` ×4 / 中心 `工作台` ×1
  （管理员也可以直接 `/cogito give develop-table <玩家> <数量>`）
- **外观是工作台**，放置后由插件接管：坐标记进**区块 PDC**（跟着区块存档，不需要额外数据库），
  方块上方挂一条全息文本（`TextDisplay`）
- **爆炸抗性同黑曜石**：TNT / 苦力怕爆炸时把开发台从方块列表里剔除，炸不掉
- **必须钻石镐或下界合金镐**才能破坏；破坏后掉落的是「开发台」物品，而不是原版工作台
- **右键打开研发界面**（潜行右键不触发，方便在方块上放东西）

## E.G.O. 专属图纸

- 每套 E.G.O. 有**自己专属的一张图纸**，物品 id 为 `blueprint-<套装id>`（例如 `blueprint-paradise-lost`）
- **图纸不是消耗品**：右键解锁该套的研发能力后，图纸仍留在玩家手上
- 解锁状态写进玩家数据（SQLite 的 `ego_unlocked`），重启、换服都还在
- 发放命令：`/cogito give blueprint <玩家> <套装id> [数量]`

## 研发流程

1. 右键专属图纸 → 解锁该套 E.G.O. 的研发能力
2. 右键开发台 → 打开研发界面
3. 界面列出所有套装：已解锁的显示「统一抗性 x / 研发消耗 / 脑啡肽是否够」；未解锁的提示需要专属图纸
4. 点击已解锁的套装 → 消耗 `ego.yml` 里 `develop.cost` 个脑啡肽（默认 64）→ 产出该套全部部件
   （四件防具 + 武器 + 饰品，一次性发放；背包放不下会掉在脚下）
5. **同一套可以反复研发**，之后不再需要图纸，只消耗脑啡肽

## 配置

`ego.yml`（每套）：

```yaml
    develop:
      cost: 64           # 研发一次消耗多少脑啡肽
      blueprint:
        material: PAPER  # 图纸外观，不填用默认
        glint: true
```

`config.yml`：

```yaml
develop:
  title: "..."              # 开发台界面标题
  hologram-text: "..."      # 方块上方的全息文本
  table-recipe:
    enabled: true           # 开发台合成表开关
```

## 顺手修的一个坑

插件自己注册的合成表现在允许使用自定义物品当材料——否则"不可合成"的脑啡肽模块根本没法做配方。

## 验证

本机 `mvn clean test package`：31 个源文件编译通过、5/5 单元测试通过，产物 `Cogito-0.5.0-BETA.jar`。
**开发台需要进游戏实测**（放置、右键界面、钻石镐限制、TNT 炸不掉），建议先在测试服过一遍。
