# Cogito 0.4.0 Beta

这一版加入 **E.G.O. 攻击通道与统一防具抗性**，并修复 Cogito 可以被当作原版跳跃药水饮用的问题。

## 新增

### 红伤 / 蓝伤攻击通道

- 攻击侧只有 `RED`（红伤）和 `BLUE`（蓝伤）。
- 蓝伤只能由手持 `attack-channel: BLUE` 的 E.G.O. 武器发起。
- 普通攻击仍作为红伤通道使用。
- `EgoDamageService` 是后续武器技能与异想体技能的伤害入口，会拒绝所有非 E.G.O. 蓝伤来源。

### E.G.O. 统一防具抗性

每个 E.G.O. 防具套装只有一个统一抗性值 `x`，对所有传入伤害生效：

```text
y = 穿戴的同一套有效 E.G.O. 防具件数（0~4）
r = 1 - (1 - x) * y / 4
最终伤害 = 当前伤害 * r
```

- `x` 不设代码范围，直接使用 `ego.yml` 中配置的数值。
- 武器和饰品不计入 `y`。
- 缺件时按件数插值，不要求必须穿满四件。
- 混入原版防具或其他 E.G.O. 防具时，整套抗性失效，统一按 `r=1`。
- 计算保持 `double`，不主动取整，最终交给 Minecraft 处理。

### E.G.O. 防具限制

- 不提供原版护甲值与盔甲韧性。
- 物品不可破坏。
- 物品不能被附魔台、铁砧或 `/enchant` 添加附魔。

### 默认示例配置

`ego.yml` 内置了一套可测试的 `失乐园`（`paradise-lost`）：

- 统一抗性 `x=0.1`
- 四件套：头饰、胸甲、护腿、战靴
- 两把测试武器：蓝伤长剑、红伤长剑
- 一个不影响抗性件数的饰品

## 修复

- Cogito 现在不能被饮用，右键不会再触发跳跃药水效果。

## 测试

- Maven 构建通过。
- `EgoMathTest` 覆盖满套、缺件、无防具、弱点和非法数值，5 项测试全部通过。
- 已在正式 Paper 1.21.11 服务端完成加载与命令自检。

## 安装

1. 把 `Cogito-0.4.0-BETA.jar` 放进 `plugins/`。
2. 重启服务端。
3. 首次启动会生成或保留 `plugins/Cogito/config.yml`、`items.yml`、`ego.yml`、`cogito.db`。
4. 使用 `/cogito give ego <玩家> paradise-lost 1` 发放测试套装。
5. 使用 `/cogito debug ego <玩家>` 查看当前件数与最终倍率。

## 环境要求

Paper 1.21.11 / Java 21 / Vault + 经济插件（使用 `/exchange` 时需要）。
