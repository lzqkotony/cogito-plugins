# Cogito 0.5.3

这一版继续修复正式服实机测试中的两个问题。

## 正义裁决者挥剑

- 改用 `PlayerAnimationEvent.ARM_SWING` 检测手臂挥动，不再依赖不稳定的 `PlayerInteractEvent` 左键判断。
- 空挥、点击实体、命中方块只要满足满蓄力条件，都能进入范围多段伤害流程。
- 实体受击事件仍保留为兜底，并通过时间窗口避免同一次挥剑重复触发。

## 服主套装命名

- 隐藏彩蛋 E.G.O.「服主」的四件防具与武器显示名称统一为 **服主**。
- 不再显示“服主之冠”“服主之甲”“服主之护腿”“服主之靴”“服主之剑”等后缀。

## 开发台显示与服主剑

- 定向研发列表现在会显示所有已配置的护甲/武器项目；未装载蓝图时显示锁定状态，不再直接把装备入口隐藏。
- 服主剑左键击杀改由手臂挥动事件触发，并继续使用 10 格目标选择范围，解决攻击伤害为 0 时无法触发的实体伤害事件问题。

## 正义裁决者护甲外观

- 四件防具统一为铁质装备外观。
- 四件防具统一使用 **钻石材质 + 海岸纹饰**。

## 验证

- `mvn clean test package`：BUILD SUCCESS，9/9 单元测试通过。
- 产物：`Cogito-0.5.3.jar`。
