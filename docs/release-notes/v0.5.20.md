# Cogito 0.5.20

## 服主 E.G.O. NPC 保护

- 识别 Citizens 写在实体上的 `NPC` metadata。
- 服主 E.G.O. 的以下操作不再作用于 Citizens NPC：
  - 左键直接击杀
  - 右键踢出
  - `PlayerInteractEntityEvent` 交互
- 普通玩家、非 NPC 生物和原有服主玩家保护规则不变。
- 提示信息：`NPC 受到服主 E.G.O. 保护`。
